# PCA (Principal Component Analysis) Streamlit App

An interactive web application built with Streamlit for performing Principal Component Analysis (PCA) on datasets, visualizing high-dimensional data, and understanding feature contributions.

🚀 **Live Demo:** [Launch PCA App](https://pca-app-11.streamlit.app/)

---

## 📌 Features

- **Data Upload**: Upload custom CSV/Excel datasets or use demo datasets.
- **Data Preprocessing**: Handle missing values, scale numeric features, and encode categorical variables.
- **PCA Decomposition**: Compute principal components, variance explained ratio, and cumulative variance.
- **Interactive Visualizations**:
  - 2D & 3D PCA Scatter Plots
  - Scree Plot / Cumulative Variance Plot
  - Feature Loadings / Biplot Analysis
- **Model Export**: Download transformed datasets and principal component metadata.
